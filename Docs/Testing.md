# QA & UI/UX Testing Log

This document tracks bug reports and UX feedback identified during manual testing.

## 1. [Bug] "Read more..." button is non-responsive
* **Issue:** Clicking the `Read more...` link on post summaries does not expand the text or perform any action.
* **Expected Result:** Clicking `Read more...` should expand the full content of the post or open a modal displaying the complete announcement.

## 2. [UX Feedback] Active Tag Highlighting in Main Feed
* **Issue:** When clicking tag buttons at the bottom of a post (e.g., `#TechNews`, `#MFU`), there is no visual indicator showing which tag is currently active in the main feed. Active selected tags are only visible inside the Filters & Subscriptions sidebar.
* **Impact:** Users can easily forget which tags are filtering the feed and miss relevant information.
